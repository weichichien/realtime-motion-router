# Configuration / 設定

This directory is reserved for external configuration files.

這個資料夾預留給未來的外部設定檔，例如：

- WebSocket source URL / WebSocket 資料來源
- OSC receiver IP addresses / OSC 接收端 IP
- UDP ports / UDP 連接埠
- Multiple receiver targets / 多個接收端

The current minimal sender uses command-line arguments instead of a configuration file.

目前最小版本先使用 command-line arguments，不使用設定檔。
